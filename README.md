# CCC Training Manual - Cyber Crime Investigation, Module by Module

A 30-module training manual on cyber crime investigation, written for police and law-enforcement learners and the investigators who train with them. One module is uploaded here every day until the full manual is public.

**Author:** Samir Raja (CYBER07) - Cyber Crime Investigator & Offensive Security Researcher - Founder, CyberHiveX Technologies

Each module is a complete 16:9 teaching deck: learning objectives, the theory explained in plain language, hands-on labs with free tools, real Indian cases with sources, and review questions.
